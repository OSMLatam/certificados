# Aviso de tratamiento de datos

- **Responsable:** {{SITE_NAME}}
- **Finalidad:** emitir y permitir la verificación de certificados de eventos.
- **Datos:** nombre, correo electrónico y, cuando la instancia lo pide, tipo y número de documento; el archivo de la credencial; registros técnicos de visita al enlace (sin dirección IP; se purgan a los 90 días).
- **Publicación:** quien conozca el enlace `/c/{slug}` puede ver el estado de la credencial. No hay listado público por evento.
- **Derechos:** para consultar, corregir o suprimir datos, escribir a {{PRIVACY_CONTACT_EMAIL}}. No hay botón de auto-baja. Corregir un certificado ya emitido se hace revocando y emitiendo uno nuevo. La supresión la ejecuta un administrador.
- **Conservación:** las credenciales emitidas se mantienen para poder verificarlas hasta que se atienda una supresión o el operador las retire.
